# 项目简介

本项目是一款基于 Flask 和机器学习的心脏病预测系统，旨在通过高效的数据处理和预测模型，帮助用户进行心脏病风险的评估。

## 核心功能

- 数据处理：系统具备对 CSV 数据文件的上传和存储能力，并将数据转换为数据库格式。
- 身份验证：利用 JWT 工具实现用户身份验证。
- 预测模型：采用机器学习算法进行心脏病预测。
- 后端文件：包括数据操作、后端函数编写、文件上传、类库引用、虚拟环境、启动文件、配置文件等。

## 适用场景

- 医疗机构：用于辅助医生进行心脏病患者的风险评估。
- 研究机构：为心脏病研究提供数据支持和预测模型。
- 个人用户：对自身心脏病风险进行初步评估。

## 技术特点

- 使用 Flask 构建 Web 后端，提供高效的数据处理和预测能力。
- 机器学习算法应用于心脏病预测，提高预测准确性。
- 详细的程序运行说明，方便用户快速上手。
